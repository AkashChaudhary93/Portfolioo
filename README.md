# Portfolioo

A bold, retro-inspired developer portfolio built with Next.js and Tailwind CSS.

## Features

- CV-driven content structure
- Branded hero, about, skills, projects, education, and contact sections
- Retro/brutalist UI with thick borders and strong contrast
- Responsive layout
- Animated hover interactions
- Spider-Man-style sticker accent
- GitHub links for featured projects

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

## Notes

This portfolio is designed to stay faithful to the CV content while keeping the visual theme bold and game-like.
